# anagrif
このリポジトリはランダムドットアナグリフを淡々と作ったものです、過度な期待はしないでください。あと画面から30㎝は離れて見てください。

とまあ、人間目って離れているじゃないですか？離れているから右目で見える形と左目で見える形が違うんですけど、これを両岸網膜像差または両眼視差って言うんですよ。

これをうまい具合にステレオグラムの数式作って散布図書くとこうなるんですよ
